این ابزار از هوش مصنوعی پیشرفته برای مدیریت کل فرآیند، از رونویسی و ترجمه تا تولید ویدیوی نهایی با زیرنویس، استفاده می‌کند.

## نحوه عملکرد

خط لوله خودکار ما:

1. **صحبت‌ها را از ویدیوی شما** با استفاده از Whisper شرکت OpenAI رونویسی می‌کند.
2. **متن را به فارسی** با استفاده از مدل M2M100 ترجمه می‌کند.
3. **زیرنویس‌های دو زبانه را تولید و همگام‌سازی** می‌کند تا به طور کامل با زمان‌بندی مطابقت داشته باشند.
4. **ویدیوی نهایی را با زیرنویس‌های چسبیده یا به عنوان فایل جداگانه** رندر می‌کند.

## پیش‌نیازها

قبل از شروع، مطمئن شوید که موارد زیر نصب شده‌اند:

- پایتون 3.11 یا بالاتر
- FFmpeg
- 8 گیگابایت رم (16 گیگابایت توصیه می‌شود)
- کارت گرافیک با پشتیبانی از CUDA برای عملکرد سریع‌تر توصیه می‌شود

## شروع سریع

1. فایل `python main.py` را اجرا کنید.
2. فایل ویدیویی را انتخاب کنید.
3. گزینه‌ها را تنظیم کنید.
4. روی "Start Processing" کلیک کنید.

## راه‌اندازی مدل آفلاین

> **هشدار:** حجم دانلود مدل M2M100 (با 418 میلیون پارامتر) بیش از **1.4 گیگابایت** است. لطفاً قبل از شروع دانلود، از فضای ذخیره‌سازی کافی و اتصال اینترنت پایدار اطمینان حاصل کنید.
> _مدل M2M100 (با 1.2 میلیارد پارامتر) بیش از **4.7 گیگابایت** است. [بیشتر بدانید](model_sizes.md)_

برای اجرای کامل مدل‌های ترجمه به صورت آفلاین و جلوگیری از هرگونه تلاش برای اتصال به سرورهای HuggingFace، این مراحل را دنبال کنید:

### 1. دانلود دستی مدل

این دستور را در ترمینال خود اجرا کنید:

```
huggingface-cli download facebook/m2m100_418M --local-dir ./models/m2m100 --local-dir-use-symlinks False
```

### 2. غیرفعال کردن دسترسی آنلاین در کد

این خطوط را قبل از بارگذاری tokenizer یا مدل خود اضافه کنید:

```
import os
os.environ["HF_HUB_OFFLINE"] = "1"
os.environ["TRANSFORMERS_OFFLINE"] = "1"
```

### 3. بارگذاری مدل‌ها فقط از فایل‌های محلی

```
self.tokenizer = M2M100Tokenizer.from_pretrained("./models/m2m100", local_files_only=True)
self.model = M2M100ForConditionalGeneration.from_pretrained("./models/m2m100", local_files_only=True)
```
